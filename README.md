# 张智 / Pekal

Personal site for job conversations, published with GitHub Pages at <https://pekalzz.github.io>.

Chinese is the default. The EN control on the page switches to American English. The page does not list a phone number, email address, or other contact details.

## Files

- `index.html` — page
- `css/styles.css` — layout
- `js/lang.js` — language toggle
- `assets/edi-order-flow.svg` — sample EDI order-flow diagram

There is no build step. `.nojekyll` is present so GitHub Pages serves the files as they are.

## Pages

This repository publishes GitHub Pages from the `main` branch, folder `/` (root). Merging to `main` updates the live site.
